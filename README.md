# Bocconi-AceV2

## Run Locally

**Prerequisites:**  Node.js
This is a test generator project of mine that helps generate bocconi entrance test level questions for more harder practice. All mocks plus 150 higher difficulty questions obtained from a bocconi student have been fed for pattern recognition. 

Note: The project is still in development stage, as there is an issue with the google studio account.
